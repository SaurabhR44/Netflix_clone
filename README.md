# 🎬 Netflix Clone – Frontend UI Replica

A pixel-perfect clone of Netflix's landing and browsing UI, built with HTML, CSS, and JavaScript. This project replicates the look and feel of Netflix for learning frontend design, layout structuring, and responsive styling.

---

## 🚀 Features

- 🎥 Netflix-style homepage UI
- 🔍 Hover effects & responsive layout
- 🎞️ Movie thumbnails carousel (dummy images/static)
- 📱 Mobile-friendly with media queries
- 🌓 Dark mode Netflix theme

---

## 🛠️ Tech Stack

- *HTML5*
- *CSS3* (Flexbox & Grid)
- *JavaScript* (for minor interactivity like sliders or dropdowns)
